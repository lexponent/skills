# Discovery-request class — research areas and output sections

Use this file when the filing is a propounded written-discovery request or a response to such a request. Discovery is typically *served* rather than filed, but the formatting and content rules governing it apply as if it were filed.

## Universal categories

US discovery practice generally distinguishes:

- **Interrogatories** — written questions answered under oath
- **Requests for admission** — statements the responding party must admit, deny, or object to
- **Requests for production / inspection demands** — requests for documents, electronically stored information, or tangible things
- **Responses** to any of the above

The structural rules differ by category and by direction (request vs. response).

## Research areas (in addition to common.md)

For requests:
- Numerical limits on the number of requests (where the jurisdiction caps them) and the procedure for exceeding the cap
- Format constraints: separately-stated and consecutively-numbered requests; rules against compound, conjunctive, or disjunctive questions; rules about subparts; rules about definitions sections
- Propounding-party identification (party identifying as propounder, set number, party to whom directed)
- Set numbering convention
- For document/inspection requests: how items must be described (reasonable particularity, categories vs. specific items); ESI-format specifications

For responses:
- Response per request (with the request restated or referenced)
- Verification under oath, signed by the responding party
- Objection format (specific grounds; treatment of boilerplate objections)
- Privilege-log or analogous requirements when withholding
- Response deadlines and extensions by service method

For both:
- Service rules (typically served, not filed; filing happens when used in motion practice)

## Output sections (in addition to common.md)

For requests:
- Identification (Propounding Party, Responding Party, Set Number)
- Definitions (conditional)
- Numerical-Limit Compliance
- Question / Request Format
- Declaration of Necessity (conditional)

For responses:
- Identification
- Response Format
- Objections
- Privilege Log (conditional)
- Verification

These lists are research hints, not output templates. Sub-categories and items emerge from the rules retrieved for the specific discovery filing in the specific jurisdiction.
